## 📌 Deskripsi Proyek
Proyek ini merupakan tugas **Lomba Kompetensi Siswa (LKS)** di bidang **Elektronika / Robotik**, yang bertujuan merancang dan membuat robot mekanum yang dapat bergerak ke segala arah, dikendalikan menggunakan **IR remote**, serta dilengkapi **Servo Gripper** untuk mengambil dan memindahkan objek.

Robot ini menggabungkan teknologi penggerak **Omnidirectional, kendali jarak jauh berbasis infrared**, dan **mekanisme penjepit (gripper)** untuk menjalankan misi pemindahan barang dengan akurasi tinggi.

---

## 🎯 Tujuan
- Mengimplementasikan konsep **kontrol otomatis** dalam sistem robotik.
- Mengasah keterampilan **pemrograman mikrokontroler**.
- Menerapkan ilmu **elektronika, mekanik, dan pemrograman** dalam bentuk nyata.
- Menunjukkan kemampuan **inovasi dan problem solving** di bidang teknologi.

---

## 🛠 Spesifikasi Teknis

| Komponen          | Detail                                       |
|-------------------|----------------------------------------------|
| **Mikrokontroler** | Arduino Uno R3                               |
| **Motor Driver**   | L293D Motor Shield                           |
| **Motor Penggerak** | 4x DC MOTOR |
| **Kendali**         | IR Remote + IR Receiver  |
| **Motor**          | DC Motor, Servo Motor                        |
| **Ban**      | 4x Ban Mekanum (Diameter 60–80 mm)                   |
| **Bahasa**         | C / C++ (Arduino IDE)                        |
| **Fitur Utama**    | - Kendali multi-arah (maju, mundur, kiri, kanan, diagonal, rotasi)<br> - Pengambilan & pemindahan objek dengan servo gripper<br> - Respon cepat terhadap perintah IR remote |
